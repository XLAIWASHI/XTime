XTime 使用说明
==================
版本 1.0.0（Windows 64 位绿色便携版）


【运行】
双击 XTime.exe 即可，无需安装。
解压后请保持 XTime 文件夹完整，不要单独移动 EXE。

【数据】
data.json 与本 EXE 同级。
  ・迁移：把整个 XTime 文件夹拷走即可。
  ・清空统计：关闭程序后删除 data.json，再次启动会自动重建。
  ・若程序放在只读目录（如 Program Files），数据会自动存到：
      %APPDATA%\XTime\data.json
    首次启动会弹一次提示告知实际路径。
  ・数据是普通 JSON，可以直接用记事本修改；改坏会备份后重建。

【基本操作】
  拖动时间区       移动窗口
  滚轮             缩放窗口（0.6× ~ 2.0×）
  点击时间区       倒计时模式下设置时长
  右键             菜单（开始/背景/颜色/字体/统计等）

【按钮】
  ▷ / ⏸   开始 / 暂停
  ↺        重置
  ⇄        倒计时 / 正计时切换
  📌       始终置顶
  📊       统计

【快捷键】
  空格             开始 / 暂停
  R                重置
  T                始终置顶
  M                倒计时 / 正计时切换
  C                颜色面板
  Ctrl + ↑ / ↓     放大 / 缩小

【背景】
  右键 → 背景 → 纯透明 / 淡灰透明。
  淡灰模式可调透明度（10% ~ 30%），还可尝试“轻量磨砂”。
  纯透明模式完全透视后方内容，不绘制任何底色。
  两种模式都会给数字加细描边，尽量保证深色/浅色壁纸下可读。

【颜色与字体】
  右键 → 时间颜色…：数字颜色、冒号颜色（可跟随数字）。
  右键 → 字体设置…：字体族、等宽筛选；数字始终为粗体 700。

【统计】
  今日 / 本周 / 本月 / 今年 / 历史总计；
  倒计时与正计时分开统计，也可看合计。
  会话按开始时间归入周期；跨午夜会话归入开始那天。
  运行中每 30 秒保存一次；暂停、重置、归零、退出时立即保存。

【倒计时】
  点击时间区或右键 → 开始/暂停 上方的时间区域；
  支持快捷时长 5 / 10 / 15 / 25 / 45 / 60 分钟，也可手动输入。
  范围 00:00:01 ~ 23:59:59；归零后弹出提示并可选提示音。
  右键 → “归零提示音”可开关声音。

【退出】
  正在计时时退出会先确认，并自动保存本次计时。

【常见问题】
  1. 双击没反应？
     确认解压完整，且 _internal 文件夹与 EXE 在同一目录。
  2. 数据在哪？
     右键 → 打开数据文件夹。
  3. 文字在浅色壁纸上不够清楚？
     改用“淡灰透明”背景，或在“时间颜色”里换深色/高对比色；
     纯透明模式会显示对比度提示。
  4. 磨砂没有效果？
     亚克力磨砂是实验性功能，部分系统/远程桌面不支持；
     失败时自动回落为淡灰底，不影响计时。
